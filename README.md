# GtS Journal (今日のニュース)

Articles du Journal de [GaijinToSensei](https://gajintosensei.com/journal) : chaque jour, l'actualité du Japon la plus pertinente de la veille, réécrite en japonais à 5 niveaux (N5 à N1).

Le site lit ce dépôt directement (aucun déploiement nécessaire) :
- `index.json` : la liste des articles, le plus récent en premier ;
- `posts/AAAA-MM-JJ/post.json` : l'article ;
- `posts/AAAA-MM-JJ/*.svg|webp|png` : les illustrations.

Le format exact est dans [FORMAT.md](FORMAT.md). Un article qui ne le respecte pas n'est pas affiché.
